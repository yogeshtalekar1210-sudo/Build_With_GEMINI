# My agent: travel-concierge-agent
One-liner: A conversational agent that helps travelers discover and plan custom trips with a catalog of destinations and itineraries.

Tool coverage:
- Memory: Traveler preferences (budget, travel style, dietary needs, past visited spots)
- Tools: Search destinations, retrieve itinerary details, fetch local weather/time
- Catalog/UI: Collection of destination cards and trip packages (A2UI)
- Image gen: Generates scenic destination artwork and landmark visual previews
- Sandbox: Budget planning and trip expense breakdowns

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch: code sandbox for budget calculations
